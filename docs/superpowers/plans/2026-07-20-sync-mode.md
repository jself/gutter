# `--sync` Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `gutter -sync`: a blocking, one-shot review that waits until the user clicks a single **Submit** button, prints the review markdown to stdout, and exits 0 without writing `review.md` — so an agent that ran gutter receives the review as command output.

**Architecture:** Add a `Sync` config field/flag/env. A new `/submit` endpoint renders the review and hands it to the main goroutine over a channel; in sync mode the main goroutine blocks on that channel, prints the markdown to stdout, and exits. In sync mode all startup logging is redirected to stderr so stdout carries only the review. The UI template gains a `Sync` flag that swaps Save/Quit/Copy for one Submit button.

**Tech Stack:** Go (single `main.go`, package `main`), `html/template`, embedded `index.html`, standard-library testing.

## Global Constraints

- **Go version floor: 1.16** (`go.mod`); no newer language features.
- **Single file:** all Go production code stays in `main.go`; tests in `main_test.go`; UI in `index.html`.
- **No new runtime dependencies** — standard library only.
- **Config precedence (highest wins):** CLI flag → env (`GUTTER_*`) → `./.gutter.json` → user config → `defaultConfig()`. A new flag MUST add the matching env var and JSON field.
- **Non-sync behavior is unchanged:** Save writes `review.md`, Quit exits, and all logging stays on stdout. `--sync` only adds a parallel path.
- **In sync mode: no `review.md` is written; stdout carries ONLY the rendered review markdown; all startup/informational logging goes to stderr.**
- **`GUTTER_SYNC` truthiness** matches `GUTTER_OPEN`: false when the value is `"0"`, `"false"`, or `"no"`; otherwise true when set non-empty.
- **`sync` JSON merge is OR, not overwrite:** a missing `sync` key must not clear an already-true value (`if f.Sync { c.Sync = true }`).

```go
		if r.Method != "POST" {
			http.Error(w, "POST only", 405)
			return
		}
		var req SaveRequest
		if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
			http.Error(w, err.Error(), 400)
			return
		}
		md := renderMarkdown(*rev, vcs, prInfo, req)

		case submitCh <- md:
		default: // already submitted; first one wins
		}

	})
```

```javascript
async function submit_review() {
  const status = document.getElementById('status');
  status.className = 'status';
  status.textContent = 'submitting…';
  const body = {
    general: document.getElementById('general').value,
    comments: COMMENTS.map(({id, ...rest}) => rest),
  };
  try {
    const r = await fetch('/submit', { method: 'POST', body: JSON.stringify(body) });
    const t = await r.text();
    if (r.ok) {
      document.body.innerHTML = '<main><p style="padding:20px;color:var(--muted)">' + escapeHtml(t.trim()) + '</p></main>';
    } else {
      status.className = 'status err';
      status.textContent = 'error: ' + t;
    }
  } catch (e) {
    status.className = 'status err';
    status.textContent = 'error: ' + e.message;
  }
}
```
